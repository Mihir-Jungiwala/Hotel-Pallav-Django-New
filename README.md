# Hotel Pallav — Accounts Panel

Django accounts/back-office app for Hotel Pallav, re-skinned to match the
brand established on [hotelpallav.in](https://github.com/Mihir-Jungiwala/hotel-pallav-website)
(Playfair Display + Inter, the violet/gold "pallav" palette, glass sidebar,
scroll and hover motion).

This is a UI-first pass, not a full rewrite — see [`docs/ui-migration.md`](docs/ui-migration.md)
for exactly what's converted, what's still on the old Bootstrap skin, and
the plan for finishing the rest.

Forked in scope from `Hotel-Pallav-Django` (that repo is untouched); this
repo carries a separate, ongoing production-readiness review at
[`docs/production-readiness-review.html`](docs/production-readiness-review.html).
